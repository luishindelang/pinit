Einstellungen

Hell / Dunkel

Gilt für dieses Brett und alle, die es öffnen — wird im Brett gespeichert. „System“ folgt der Einstellung des Betrachters.

Mausrad / Touchpad

Wie in Figma: Rad schiebt die Fläche (Touchpad in alle Richtungen), Strg+Rad zoomt, Kneifen auf dem Touchpad zoomt, Umschalt+Rad schiebt waagerecht. „Rad zoomt“ ist für Maus-Nutzer, die ohne Strg zoomen wollen. Gilt nur für dieses Fenster.

Raster

An/Aus und Schrittweite stehen unten rechts am Knopf „Raster“ und gelten nur für dieses Fenster. Das Raster greift an der Mitte eines Elements — so liegen verschieden große Elemente auf einer Linie.

Für Claude

Jedes Element hat im Inspektor unter „Für Claude“ eine Notiz (Details, Verhalten, Regeln), einen Verweis (Datei, URL, Ticket) und einen Status. Die Kennung oben im Inspektor (Klick kopiert) benennt ein Element gegenüber Claude eindeutig.

Einfrieren oben rechts sperrt das Brett für alle, auch für Claude — das ist die Fassung, gegen die gebaut wird. Diagramm-Text kopiert den offenen Reiter als Mermaid.

Claude liest und schreibt dieses Brett über die Artifact-Datenbank (Skills pinit-lesen, pinit-schreiben). Die Seite selbst kann jederzeit aktualisiert werden, der Inhalt bleibt.

Leeres Brett

Werkzeug oben wählen, dann auf der Fläche die Größe aufziehen — ein einzelner Klick nimmt die Standardgröße. Ziehen auf leerer Fläche wählt einen Bereich aus; die Ansicht verschiebt das Werkzeug „Bewegen“ (H) oder die mittlere Maustaste, Mausrad zoomt.
